In one place, by one rule.

- `api/internal/invoice/invoice.go` has `roundDiv`, which rounds half away from zero. Nothing else in the api divides an amount.
- It's called from `Line.Tax`, once for each line. That's the penny in `invoice-totals-off-by-a-penny`: the fix there calls it once for each rate.
- The dashboard never rounds. `web/src/invoices/money.ts` is given minor units and divides by 100 only to show them.

ADR 0001 says a rounding is a decision, written down where it's made. It doesn't say which way we round, so that's worth a line there once the fix lands.
